Section 1

→→ elements are things in the message which give it functions - such as lines, without having to draw them.

The following is the format of interactive-element

?interactive-element(v1)["{{type}}"::"{{data}}"]//

?interactive-element(v2)["{{type}}=={{name}}=={{data}}=={{notes-plaintext}}"]//

→→interactive-element v1 syntax

{{type}}: lines, image, drafter

→{{data}} syntax:

lines: ln={{number of lines}}

image: src={{online image directory}}

drafter: mc={{max chars}}::txt={{text}}
